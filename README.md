# Dad Shed

A small website for neighbors who would rather borrow a drill than buy another one.

This first version shows a sample shelf and lets you ask the group for something that is not listed. Asks stay in the computer's memory and disappear when the app stops. Sign-in, invites, and a saved list come later.

## Run it on your computer

You need [Node.js 22](https://nodejs.org/).

```bash
npm ci
npm run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

## Check it

```bash
npm test
npm run lint
npm run typecheck
npm run build
```
